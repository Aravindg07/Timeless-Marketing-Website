# Timeless Marketing: Portfolio Website

Single-file portfolio site for Timeless Marketing (`index.html`). No build step or dependencies.

## Edit content
Open `index.html` and edit the `CONFIG` block near the top of the `<script>`:
- `contact`: email, WhatsApp number (digits with country code), extra phone numbers
- `projects`: client name, industry, location, description, Instagram and Facebook links
- `commonServices`: services shown for every client

## Run locally
Double-click `index.html`, or run `python3 -m http.server` and open http://localhost:8000

## Deploy
Hosted with GitHub Pages
